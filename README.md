## ✨ امکانات کلیدی

- ⚡ **پردازش مستقیم لبه ابری (Edge Computing):** عملکرد فوق‌العاده پایدار و با سرعت حداکثری بر بستر شبکه جهانی Cloudflare Workers.
- 🗄️ **پایگاه‌داده توزیع‌شده D1:** مدیریت امن نشست‌ها، تنظیمات و اطلاعات پیشخوان در دیتابیس بومی ابری کلودفلر بدون نیاز به سرور واسط.
- 🌐 **پشتیبانی از پروتکل‌های استاندارد شبکه:** پشتیبانی همزمان از استانداردهای نوین ارتباطی **VLESS**، **Trojan** و **Shadowsocks**.
- 🎨 **پیشخوان وب لوکس و هوشمند (Modern Dashboard):** رابط کاربری پیشرفته Glassmorphism با تم تاریک اختصاصی، مانیتورینگ زنده نودها و تولید آنی لینک‌های اشتراک.
- 🛡️ **استقلال ۱۰۰٪ و بدون تک‌نقطه شکست (Zero-SPOF):** بدون وابستگی به هیچ سرور جانبی؛ پنل کاملاً مستقل و ایزوله روی حساب کلودفلر شخصی شما اجرا می‌شود.

## 🤖 نحوه راه‌اندازی سریع با ربات تلگرام

برای استقرار و دریافت پنل اختصاصی، کل فرآیند از طریق ربات رسمی تلگرام انجام می‌پذیرد:

<div align="center">

### 🚀 [ورود مستقیم به ربات تلگرام (@IronKimeraBot)](https://t.me/IronKimeraBot)
**📢 [عضویت در کانال رسمی اطلاع‌رسانی (@IronKimera)](https://t.me/IronKimera)**

</div>

1. وارد ربات **[@IronKimeraBot](https://t.me/IronKimeraBot)** شوید.
2. دستور `start/` را ارسال فرمایید.
3. کلید دسترسی کلودفلر (**Cloudflare API Token**) با مجوزهای `Workers: Edit` و `D1: Edit` را برای ربات بفرستید.
4. ربات به صورت خودکار:
   - پایگاه‌داده D1 را روی حساب ابری شما فعال می‌کند.
   - سیستم را مستقر و بهینه‌سازی می‌نماید.
   - لینک پیشخوان اختصاصی و آدرس تعریف رمز عبور مدیریت (`setup/`) را به شما تحویل می‌دهد.

## 🔒 حریم خصوصی و معماری

- **معماری بدون لاگ (Zero-Log):** تمام بسته‌ها به طور مستقیم بر روی زیرساخت کلودفلر پردازش شده و هیچ سرور میانی برای رصد یا ذخیره ترافیک وجود ندارد.
- **بدون رمز پیش‌فرض:** هیچ کلید یا رمز عبور هاردکدشده‌ای وجود ندارد؛ تنظیم رمز برای اولین بار به انتخاب خود شما در صفحه امن `/setup` انجام شده و در دیتابیس D1 رمزنگاری می‌گردد.
- **انزوای کامل داده‌ها:** تمامی پیکربندی‌ها تنها در محدوده حساب کاربری خودتان مدیریت می‌شوند.
